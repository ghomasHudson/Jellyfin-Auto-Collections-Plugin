Trakt

Paste a supported public Trakt URL under Source list URLs and select Save. With the bundled Client ID, you don't need to sign in to Trakt or register an app.

Magic Collections uses Trakt but is not endorsed or certified by Trakt.

Client ID override (optional)

For development or self-built installs, you can use your own Trakt app. Link a verified GitHub account in the Developer panel under Trakt My Apps, then create a Trakt API app.

A personal app can stay in Development. If Trakt asks for a redirect URI, enter http://localhost; the plugin does not use it.

Paste only the Client ID, or leave blank to use the bundled ID.
