Source list URLs

Add URLs for supported source lists.

Sync removes titles from managed collections if they don't match the source list. It doesn't delete media from your library.

*arr

Enter each Radarr or Sonarr server's base URL (including any reverse proxy path) and its API key. Use a different base URL for each server. Under Source list URLs, add the base URL followed by the tag label, for example https://media.example.com/radarr/family-movies or https://media.example.com/sonarr/family-shows. Never put a key in a URL.

Trakt

Public lists and charts don't require a Trakt account. Connect Trakt to import your private lists, watchlist, or personalized recommendations using Source list URLs above.

Checking Trakt connection…

  1. Open Trakt and approve access in a new tab.
  2. Click Copy response on the callback page, then paste it here.

Magic Collections uses Trakt but is not endorsed or certified by Trakt.
